## What this skill does

Give it **one keyword** and it will:

- **Expand the keyword** into sub-keywords, related keywords, similar keywords, semantic entities, and question (PAA) keywords.
- **Build an SEO strategy** — search intent, keyword map, H1/H2/H3 structure, featured-snippet opportunities, topical authority plan.
- **Research & fact-check** using trustworthy sources, with verified-vs-inferred labeling.
- **Write a complete, publication-ready article** optimized for WordPress.
- **On-page SEO** — SEO title, meta description, URL slug, focus keyphrase, schema recommendation.
- **Yoast SEO readiness** check (readability, keyphrase placement, headings).
- **Google Search & E-E-A-T quality** review (Experience, Expertise, Authoritativeness, Trustworthiness).
- **AdSense-friendly editorial review**.
- **Deliver all 12 outputs** (A–L): strategy, keyword map, title, meta, slug, article, FAQ, linking plan, image/alt recommendations, schema, checklist, limitations.

## Usage

Just provide a single keyword (or topic/title). Optional details (audience, tone, word count, niche, intent, competitors) can be added; sensible defaults are inferred when omitted.

Example:
> Write an SEO blog article about "best mechanical keyboard for programming"

## Deliverables

A. SEO strategy & search intent
B. Keyword map (primary / secondary / long-tail / entities / questions)
C. Final SEO title
D. Meta description
E. URL slug & focus keyphrase
F. Complete publication-ready article (WordPress-ready)
G. FAQ section
H. Internal & external linking plan
I. Featured image & alt-text recommendations
J. Relevant schema recommendation
K. Final Yoast SEO & editorial checklist
L. Remaining issues / fact-checking limitations
